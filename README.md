# JARVIS-BrowserInfoGrabber
Just a JARVIS-style HUD to display some public information about the Browser and Operating System.

## Quick Warning: 
All the info that is grabbed by this probably don't leave the browser, that is, it's local. "Probably" because I don't know how Github Pages work with this type of thing, but in the code there's no telemetry that sends it anywhere, you can check by yourself. The only thing that uses external third-party connections is the IP grabber/fetch that sends a fetch request to "ipify.org" to get the IP address (which is probably public info anyways, I don't fully know how IPify works), you can check it yourself if you want to.
